本任务学什么

文言文的特殊句式,是相对于现代汉语而言的,在古代实际是一种正常的句式。这些句式随着语言的发展逐步发生了改变,在现代汉语中却成了变式句或特殊句式。这些句式包括:判断句、被动句、省略句、固定句式、倒装句等。

一、判断句

判断句是对事物的性质、情况、事物之间的关系作出肯定或否定判断的句子。

类型形式例句
在主语后加“者”表停顿,在谓语后加“也”表判断……者,……也陈胜者,阳城人也。(《陈涉世家》)
……者,…………,……者也①兵者,不祥之器。(《老子》)②莲,花之君子者也。(《爱莲说》)
……,……也赂秦而力亏,破灭之道也。(《六国论》)
无标志,直接判断:既不用判断词,也不用语气词,通过语意直接表示判断……,……①臣本布衣。(《出师表》)②今臣亡国贱俘。(《陈情表》)
用“为”“是”表判断……为(是)……①如今人方为刀俎,我为鱼肉。(《鸿门宴》)②不知木兰是女郎。(《木兰诗》)
用“乃”“则”“皆”“诚”等表判断①当立者乃公子扶苏。(《陈涉世家》)②此则岳阳楼之大观也。(《岳阳楼记》)③亭东自足下皆云漫。(《登泰山记》)④此诚危急存亡之秋也。(《出师表》)
用“非”或“匪”表否定判断……非(匪)……①六国破灭,非兵不利。(《六国论》)②所守或匪亲。(《蜀道难》)

1.此国士之容也。(2025·北京卷)

二、被动句

所谓被动,是指主语与谓语之间的关系是被动关系,也就是说,主语是谓语动词所表示行为的被动者、受事者,而不是主动者、施事者。在古代汉语中,主语是谓语动词所表示行为的被动者的句式叫被动句。被动句主要有两大类型:一是有标志的被动句,即借助一些被动词来表示被动;二是无标志的被动句,又叫意念被动句。

类型例句
有标志的被动句“于”字句:谓语+于六艺经传皆通习之,不拘于时。(《师说》)
“见”字句:见+谓语或见+谓语+于①渐见愁煎迫。(《孔雀东南飞并序》)②臣诚恐见欺于王而负赵。(《廉颇蔺相如列传》)
“受”字句:受+谓语+于吾不能举全吴之地,十万之众,受制于人。(《赤壁之战》)
“为”字句:为+动词身死人手,为天下笑者,何也?(《过秦论》)
“为……所”“为所”句①有如此之势,而为秦人积威之所劫。(《六国论》)②不者,若属皆且为所虏!(《鸿门宴》)
“被”字句信而见疑,忠而被谤。(《屈原列传》)
无标志的被动句(意念被动句)①洎牧以谗诛。(《六国论》)②而刘夙婴疾病。(《陈情表》)

应用体验

1.对照原文判断下列对加点词语及相关内容的解说是否正确。

(2023·新课标Ⅰ卷第11题A项)围,指被围困,“傅说举于版筑之间”的“举”表示被选拔,两者用法相同。(　　)

原文信息襄子围于晋阳中,出围,赏有功者五人,高赫为赏首。
查看答案

√　两者都表示被动用法。

(1)陵之族也,则嫁其祸于李绪。(2024·新课标Ⅰ卷)

分析:

(2)六国之亡,皆灭于秦兵。(2024·新课标Ⅱ卷)

分析:

(3)布为操所擒。(2024·全国甲卷)

分析:

分析:

三、省略句

文言文语句中根据习惯,省略某词或某种成分的句子叫省略句。因此,在省略句中补足省略成分有助于完整理解句子的意思。省略句主要有以下六种类型:

类型例句
省略主语承前省略沛公军霸上,(沛公)未得与项羽相见。(《鸿门宴》)
蒙后省略(公)度我至军中,公乃入。(《鸿门宴》)
对话中省略樊哙曰:“今日之事何如?”良曰:“(今日之事)甚急!”(《鸿门宴》)
省略谓语承前省略择其善者而从之,(择)其不善者而改之。(《论语》)
蒙后省略杀人如(恐)不能举,刑人如恐不胜。(《鸿门宴》)
共喻省略(根据上下文一看便会明白省略的是什么)“公之视廉将军孰与秦王(厉害)?”曰:“不若也。”(《廉颇蔺相如列传》)
省略宾语动词宾语省略项伯乃夜驰之沛公军,私见张良,具告(之)以事。(《鸿门宴》)
介词宾语省略竖子不足与(之)谋!(《鸿门宴》)
省略介词介词“于”省略列坐(于)其次。(《兰亭集序》)
介词“以”省略陈胜、吴广皆(以)次当行。(《陈涉世家》)
介词“自”省略两岸青山相对出,孤帆一片(自)日边来。(《望天门山》)
省略兼语使(汝)决人死生。(《苏武传》)
分句省略项伯杀人,(按律当斩)臣活之。(《鸿门宴》)

应用体验

分析下列省略句的特点。

1.其邻假以买取鼠之狗。(2025·北京卷)

分析:

2.其邻畜之数年而不取鼠,以告相者。(2025·北京卷)

分析:

3.郑伯如晋,子大叔相。(2025·全国一卷)

分析:

4.温迁大司马,又转为参军。(2025·全国二卷)

分析:

5.单于匿之北方。(2024·新课标Ⅰ卷)

分析:

6.秦之与魏,孟贲之与童子也。(2024·新课标Ⅱ卷)

分析:

查看答案

1.“假”后省略代词宾语“之(代善相狗者)”,应为“其邻假(之)以买取鼠之狗”　2.“以告相者”前省略主语“其邻”,应为“(其邻)以告相者”　3.“相”后省略宾语“郑伯”,应为“郑伯如晋,子大叔相(郑伯)”　4.省略兼语“超”,应为“又转(超)为参军”　5.省略介词,应为“单于匿之(于)北方”　6.省略谓语,应为“秦之与魏,(犹)孟贲之与童子也”

四、固定句式

固定句式也叫固定结构或凝固结构。它的语法特点就是由一些不同词性的词凝结在一起,固定成为一种句法格式,表达一种新的语法意义,约定俗成,经久不变。熟练地掌握这些固定结构,可以收到事半功倍的效果,对快速、正确地进行文言文翻译非常有帮助。现将常见的固定句式汇集如下:

类型句式标志翻译格式
表示疑问语气奈何怎么办,为什么
何如怎么样
何以……凭什么……
如……何对……怎么办
孰与……跟……比较,哪一个……
表示反问语气何……为为什么要……呢
何……之有有什么……呢
不亦……乎不也是……吗
其……乎哪里……呢
顾……哉难道……吗
表示感叹语气何其多么
一何何等,多么
唯(惟)……是……强调语气,“是”是提宾作用,无意义
直……耳只是……罢了
表示揣度语气无乃……乎(与)恐怕……吧;只怕……吧
得无……乎恐怕……吧
其……欤岂不是……吗
表示陈述语气无以没有用来……的东西、办法
有所……有……的人或物或事
无所……没有什么……的
比及等到……的时候
表示选择关系与其……孰若……与其……,不如……
其……邪(耶),其……邪(耶)是……呢,还是……呢
表示假设关系然则……既然这样,那么……;如果这样,那么……

应用体验

翻译下面的句子,注意固定句式。

(1)(2023·新课标Ⅱ卷第13题)请君少却,令将士得周旋,仆与诸君缓辔而观之,不亦乐乎!

译文:

(2)(2022·全国乙卷第13题)武王克殷,召太公而问曰:“将奈其士众何?”

译文:

查看答案

(1)请您稍稍后退,让将士们得以展开战斗,我与各位骑马慢行观战,不也是很愉快吗?(“不亦……乎”,固定句式,不也是……吗)

(2)武王战胜了殷商,召见太公而问道:“将如何对待他们的官员和民众呢?”(“奈……何”,固定句式,如何对待……呢)

五、倒装句

为了强调、突出某个词语而颠倒原有语序的句式叫作倒装句。在倒装句中,颠倒了的成分可以恢复原位而句意基本不变,句法成分不变。文言倒装句式分为宾语前置句、定语后置句、状语后置(介词结构后置)句、主谓倒装句等。

1.宾语前置句

现代汉语中,宾语一般处于谓语之后,用来回答是“谁”或是“什么”的;而在古代汉语中,却往往出现宾语放置在谓语动词之前的情况,这种句子就叫宾语前置句。其常见的类型有以下几种:

类型例句
疑问句中代词作宾语大王来何操?(《鸿门宴》)
否定句中代词作宾语古之人不余欺也!(《石钟山记》)
用“之”或“是”为标志,强调宾语①句读之不知,惑之不解。(《师说》)②唯利是图(成语)
无标志一言以蔽之。(《论语》)

2.定语后置句

定语后置句是指为了强调和突出定语所表现的内容,把定语放到了中心词之后的一种特殊的文言句式。定语后置句的类型主要有以下几种:

类型例句
中心词+后置定语+者客有吹洞箫者,倚歌而和之。(《赤壁赋》)
中心词+之+后置定语①蚓无爪牙之利,筋骨之强。(《劝学》)②凌万顷之茫然。(《赤壁赋》)
中心词+之+后置定语+者石之铿然有声者,所在皆是也。(《石钟山记》)
中心词+而+后置定语+者缙绅而能不易其志者。(《五人墓碑记》)
中心词+数量词我持白璧一双,欲献项王。(《鸿门宴》)

3.状语后置(介词结构后置)句

在现代汉语中,介词结构经常放在谓语或主语之前,作句中或句前状语;而在文言文中,这种介词结构却经常放在谓语动词后面,所以这种句子被称为状语后置(介词结构后置)句。状语后置(介词结构后置)句一般有以下几种类型:

类型例句
用“于”字构成介词结构,后置①月出于东山之上。(《赤壁赋》)②以其无礼于晋,且贰于楚也。(《烛之武退秦师》)
用“以”字构成介词结构,后置私见张良,具告以事。(《鸿门宴》)
用“乎”字构成介词结构,后置生乎吾前,其闻道也固先乎吾。(《师说》)

4.主谓倒装句

古汉语中,为了强调和突出谓语的意义,在一些疑问句或感叹句中,就把谓语提到主语前面,构成主谓倒装句。翻译时要根据语意、语气表达的需要,适当调整主语、谓语的顺序。主谓倒装句主要有两种类型:

类型例句
表疑问语气安在公子能急人之困也!(《信陵君窃符救赵》)
表感叹语气甚矣,汝之不惠!(《愚公移山》)

应用体验

1.对照原文判断下列对加点的词语及相关内容的解说是否正确。

(2023·全国甲卷第11题B项)何怨,怨恨什么。“多歧路,今安在”中“安在”表示在哪里,两者结构相同。(　　)

原文信息尝知汀州宁化县,提点刑狱杨纮入境,微伺刺史善否,有被刑而耘苗者,纮就询其故。对曰:“贫以利故,为人直其枉,令不可欺,而我欺之,我又何怨?”
查看答案

√　两者结构上都是疑问句中疑问代词作宾语,前置。

2.分析下列倒装句的特点。

(1)难动以物而必不妄折。(2025·北京卷)

分析:

(2)则以步卒五千出塞。(2024·新课标Ⅰ卷)

分析:

(3)文侯由此得誉于诸侯。(2024·新课标Ⅱ卷)

分析:

(4)彼何为者?(2024·新课标Ⅱ卷)

分析:

(5)善赏哉,襄子!(2023·新课标Ⅰ卷)

分析:

查看答案

(1)状语后置句,“以物”作“动”的后置状语　(2)定语后置句,“五千”是“步卒”的后置定语　(3)状语后置句,“于诸侯”作“得誉”的后置状语　(4)宾语前置句,疑问代词“何”作宾语,前置　(5)主谓倒装句,“襄子”是主语,“善赏哉”是谓语

课时作业

答案与解析默认折叠，先自己做，再点开核对。

阅读材料

二、(2025·河南安鹤焦濮二模)阅读下面的文言文,完成6—10题。

材料一:

王通,字仲淹,龙门人。通诣阙献《太平十二策》,帝①不能用。罢归,教授于河、汾之间,弟子自远至者甚众。累征不起。杨素甚重之,劝之仕。通曰:“通有先人之敝庐足以庇风雨,薄田足以供粥,读书谈道足以自乐。愿明公正身以治天下使时和年丰通也受赐多矣不愿仕也。”或谮于素曰:“彼实慢公,公何敬焉?”素以问通,通曰:“使公可慢,则仆得矣;不可慢,则仆失矣。得失在仆,公何预焉?”素待之如初。

弟子问息谤,曰:“无辨。”问止怨,曰:“不争。”尝称:“无赦之国,其刑必平;重敛之国,其财必削。”大业末,卒于家,门人谥曰:文中子。

(节选自《历代名臣言行录》)

材料二:

房玄龄问事君之道,子②曰:“无私。”问使人之道,曰:“无偏。”曰:“敢问化人之道?”子曰:“正其心。”问礼乐,子曰:“王道盛,则礼乐从而兴焉,非尔所及也。”或问杨素,子曰:“作福、作威、玉食,不知其他也。”

陈叔达为绛郡守,下捕贼之令曰:“无急也,请自新者,原之,以观其后。”子闻之曰:“陈守可与言政矣。上失其道,民散久矣。苟非君子,焉能固穷?导之以德,悬之以信,且观其后,不亦善乎?”

子在长安,杨素、苏夔、李德林皆请见。子与之言,归而有忧色。门人问子,子曰:“素与吾言,终日言政而不及化。夔与吾言,终日言声而不及雅。德林与吾言,终日言文而不及理。”门人曰:“然则何忧?”子曰:“非尔所知也。二三子皆朝之预议者也,今言政而不及化,是天下无礼也;言声而不及雅,是天下无乐也;言文而不及理,是天下无文也。王道从何而兴乎?吾所以忧也。”门人退。子援琴鼓《荡之什》③,门人皆沾襟焉。

杨素谓子曰:“天子求善御边者,素闻惟贤知贤,敢问夫子?”子曰:“羊祜、陆逊,仁人也,可使。”素曰:“已死矣,何可复使?”子曰:“今公能为羊、陆之事,则可。如不能,广求何益?通闻迩者悦,远者来,折冲樽俎可矣,何必临边也?”

(节选自《文中子中说》)

[注] ①帝:隋文帝。②子:指王通,家学深厚,时称“王孔子”。③《荡之什》:召穆公所作伤周室大坏之诗。

材料一:

王通,字仲淹,是龙门人。王通曾到朝廷进献《太平十二策》,但隋文帝没有采纳。他辞官回乡,在黄河、汾水一带教授学生,从远方来求学的弟子很多。朝廷多次征召,他都不去就职。杨素非常器重他,劝他出仕。王通说:“我有祖先留下的破屋,足以遮风避雨;有几亩薄田,足以糊口;读书论道,足以自得其乐。希望明公(指杨素)能端正自身以治理天下,使时局太平、五谷丰登,这样我也算是受惠良多了,不愿出仕。”有人向杨素说王通的坏话:“他实在是怠慢您,您为什么敬重他呢?”杨素拿这话问王通,王通答道:“如果明公是可以被轻慢的,那是我有所得;如果明公不可轻慢,那是我有所失。得失在我,与明公何干?”杨素仍像以前一样待他。

弟子问他如何平息诽谤,他说:“不辩解。”问他如何消除怨恨,他说:“不争执。”他曾说:“不赦免罪行的国家,刑罚必定公正;横征暴敛的国家,财富必定减少。”大业末年,王通在家中去世,门人追谥他为“文中子”。

材料二:

房玄龄问侍奉君主的方法,王通说:“无私。”问用人之道,他说:“不偏私。”又问:“请问教化百姓的方法?”王通说:“端正他们的心。”问礼乐之事,王通说:“王道兴盛,礼乐自然随之兴起,这不是你现在能考虑的。”有人问杨素的为人,王通说:“他只知道作威作福、享受奢靡,别的就不清楚了。”

陈叔达任绛郡太守时,下令抓捕盗贼时说:“不必急于捉拿,愿意改过自新的,可以宽恕,以观后效。”王通听说后评价道:“陈太守可以和他谈论政事了。朝廷失道,百姓离心已久。若非君子,怎能安于贫困?以德引导,以信约束,再观察他们的表现,不也很好吗?”

王通在长安时,杨素、苏夔、李德林都来求见。王通和他们交谈,回去后面露忧色。弟子问他原因,王通说:“杨素和我交谈,谈了一整天政事,却丝毫不提教化。苏夔和我交谈,谈了一整天音律,却丝毫不提雅乐。李德林和我交谈,谈了一整天文章,却丝毫不提义理。”弟子问:“那您为何忧虑?”王通说:“你们不懂。这几人都是参与朝政的大臣,如今只谈政事而不提教化,说明天下已无礼制;只谈音律而不提雅乐,说明天下已无正声;只谈文章而不提义理,说明天下已无真文。这样王道如何兴盛?我因此忧虑。”弟子退下。王通弹奏《荡之什》,众人听了都泪湿衣襟。

杨素对王通说:“皇帝寻求善于守卫边疆的人,我听说只有贤人了解贤人,冒昧地问先生怎么看?”王通说:“羊祜、陆逊都是仁德之人,可以任用。”杨素说:“他们已经去世了,怎么能再用?”王通说:“如果明公能效仿羊祜、陆逊的仁政,自然可行。若不能,广求人才又有何用?我听说,能让近处的人悦服,远方的人自然归附,在朝堂上运筹帷幄即可,何必亲临边境?”
