题材一　咏史怀古诗

知识梳理

题材特征思想情感常用技法
内涵以历史事件、历史人物、历史陈迹等为题材,借咏叹史实、描写古迹来抒发诗人的兴衰之感①借古人抒发自己怀才不遇的感慨;类比古人,寄托伤感或哀思②缅怀前贤,表达敬仰或惋惜③借论古之得失,托古讽今,忧国忧民④针对历史人物或事件,发表自己的看法①“诗”与“史”结合:用典②“咏史”与“言志”结合:借古讽今③“古”与“今”结合:对比、衬托、虚实结合④“景”与“情”结合:借景抒情(寓情于景)
标志标题中有古迹、古人名,或有“咏史”“怀古”等①借古人抒发自己怀才不遇的感慨;类比古人,寄托伤感或哀思②缅怀前贤,表达敬仰或惋惜③借论古之得失,托古讽今,忧国忧民④针对历史人物或事件,发表自己的看法①“诗”与“史”结合:用典②“咏史”与“言志”结合:借古讽今③“古”与“今”结合:对比、衬托、虚实结合④“景”与“情”结合:借景抒情(寓情于景)

经典例题

(2025·湖北部分高中协作体三模)阅读下面这首清诗,完成1—2题。

登雨花台①
魏　禧②
生平四十老柴荆③,此日麻鞋④拜故京。
谁使山河全破碎?可堪翦伐⑤到园陵⑥!
牛羊践履多新草,冠盖⑦雍容半旧卿。
歌泣不成天已暮,悲风日夜起江生。

[注] ①此诗作于1663年(康熙二年),距明朝灭亡已二十年。作为长期隐居故乡、不愿出仕清朝的遗民诗人,魏禧四十岁时来到旧京南京,登上雨花台(今南京中华门外),仍感慨万千,写下这首七律。②魏禧:生于明末,明亡后,隐居翠微山。③老柴荆:老于茅屋,表示甘守贫贱。④麻鞋:麻编的鞋子,乡间野老所穿,杜甫曾以“麻鞋见天子,衣袖露两肘”的诗句表示对唐王朝的耿耿忠心。⑤翦伐:采伐。⑥园陵:南京钟山的明太祖朱元璋墓。⑦冠盖:官僚们的华贵冠服车盖。

1.下列对这首诗的理解和赏析,不正确的一项是(　　)(3分)

  • A开头一句交代了诗人年至四十仍甘心老于茅屋,不仅点明了诗人的布衣身份,而且还隐含着一股不屈之气。
  • B“可堪翦伐到园陵”一句,既有对断送国家者的鞭挞,也有对异族入侵者的控诉,表达了痛心疾首的义愤之情。
  • C颈联中的“牛羊践履”,既是实写眼前牛羊践踏皇家园陵的景象,又是对异族侵略者的微妙讥讽。
  • D“冠盖雍容半旧卿”是说园陵里有一半的前朝雍容的官员,在异族入侵后的悲惨遭遇,表达了诗人对他们的敬仰。
查看答案

D

查看解析

“半旧卿”是指那些曾在明朝为官为宦的权贵们,在异族入侵者面前卑躬屈膝,侧姿求媚,摇身又变成了当朝的新贵,表达了诗人对他们的蔑视和批判。

2.有人评价魏禧的诗歌多抒写故国之思和国破之悲。请分析这首诗是如何表现国破之悲的。(6分)

查看答案

①直抒胸臆。“谁使山河全破碎”,诗人直抒胸臆发出了激愤,表现了诗人对祸国殃民者的刻骨仇恨和国破的悲痛之情。②借景抒情。“悲风日夜起江生”一句,含蓄委婉地表达了诗人的悲愤之情。③对比。“多新草”与“半旧卿”,通过一新一旧的对比,表达了诗人国破的悲痛之情。(每点2分)

查看解析

①直抒胸臆。“谁使山河全破碎?可堪翦伐到园陵!”诗人心头的怒火陡然升起,直接发出了激愤的责问:究竟谁是国家灭亡的罪魁祸首?表现了诗人对祸国殃民者的刻骨仇恨和国破的悲痛之情。②借景抒情。“悲风日夜起江生”,悲风猎猎,吹起大江呜咽声。描写了凄风悲号、江水痛哭、日夜不息的景象,把诗人的悲愤之情融入景物的描绘之中,以景结情,含蓄委婉。③对比。“多新草”与“半旧卿”,一新一旧,新草遮盖的是旧日山河,旧卿却扮演了新贵的角色,通过对比,表达了诗人国破的悲痛之情。

题材二　咏物言志诗

知识梳理

题材特征思想情感常用技法
内涵以某一物为描写对象,抓住其某些特征着意描摹,借以表达作者的思想感情①寄寓作者的理想抱负,或实现个人理想,或报效国家②寄寓高尚的节操,或表达怀才不遇与命运多舛的伤感,或抒发年华易逝与理想破灭的哀愁③托物讽世,或忧国忧民,或感时伤世,或愤世嫉俗,或针砭时弊①表现手法:托物言志、象征、衬托②修辞手法:比喻、拟人、对比③描写手法:正面描写(绘形绘色)与侧面衬托
标志①从对象上来看,咏物诗的对象是单纯的某个物。着重对所咏之物的特征、功能进行刻画,或者着重对所咏之物的某一内蕴、精神进行吟咏②从题目上来看,或以所咏之物为诗名,或以“咏某物”“题某物”“某物吟”等为题目形式①寄寓作者的理想抱负,或实现个人理想,或报效国家②寄寓高尚的节操,或表达怀才不遇与命运多舛的伤感,或抒发年华易逝与理想破灭的哀愁③托物讽世,或忧国忧民,或感时伤世,或愤世嫉俗,或针砭时弊①表现手法:托物言志、象征、衬托②修辞手法:比喻、拟人、对比③描写手法:正面描写(绘形绘色)与侧面衬托

经典例题

(2025·广东深圳一模)阅读下面两首宋诗,完成1—2 题。

初见杏花
梅尧臣
不待春风遍,烟林独早开。
浅红欺醉粉,肯信有江梅?
和梅圣俞杏花
欧阳修
谁道梅花早,残年岂是春?
何如艳风日,独自占芳辰。

1.下列对这两首诗的理解和赏析,不正确的一项是(　　)(3分)

  • A梅诗前两句点题,诗人于早春时节雾气萦绕的树林见到刚刚开放的杏花。
  • B梅诗以“醉粉”指代梅花,并以“肯信有江梅”暗示其花事已接近尾声。
  • C欧诗以“岂是”来表示反问,明确反对世人认为残冬里也有春天的观点。
  • D两诗一唱一和,都将杏花与梅花进行比较,也都有意突出早春杏花之美。
查看答案

C

查看解析

世人认为“梅花开花很早”,但欧阳修认为“梅花开花不算早”,并用“残年岂是春”来支持观点。作者认为,残冬开放的梅花比不上早春独占芳辰的杏花,残冬的“早”没有意义,春天的“早”才是真正的早。

2.这两首诗借花来表达不同的哲理。请结合相关内容简要分析。(6分)

查看答案

①梅诗认为杏花虽早开却浅红,未必美于江梅,暗含美在各有时节,不必相争之意;②欧诗认为梅花虽被公认为早春之花,却不及杏花明艳于盛春时日,突出美在盛时的观点。(每点3分)

查看解析

①梅诗认为杏花虽早开,颜色浅红,未必比梅花更美。诗人通过“浅红欺醉粉,肯信有江梅”暗示杏花虽早,但梅花的美也不逊色,表达了“美在各有时节,不必相争”的观点。杏花和梅花各有其美,一个早开,一个迟开,各有其存在的意义,无须争高低。②欧诗则认为梅花虽被公认为早春之花,但它的开放时节并非真正的春天(“残年岂是春”)。而杏花在真正的春天(“艳风日”)开放,独自占据最美的时光,表达了“美在盛时”的观点,即杏花的美在于它盛开于真正的春天,而不是像梅花那样在残冬开放。

题材三　边塞征战诗

知识梳理

题材特征思想情感常用技法
内涵以边疆地区军民生活和自然风光为题材①保家卫国、建立功名的壮志豪情②奋勇杀敌、英勇无畏的英雄气概③雄奇瑰丽、奇异独特的边塞风光④征人思乡、闺妇盼归的两地情愁⑤凄苦哀怨的怨战情绪,凄厉沉痛的反战思考⑥对和平安宁的边疆生活、和睦友好的民族往来的喜爱①修辞手法:主要有夸张、互文、对比、用典等②人物塑造手法:常用侧面烘托、动作描写、肖像描写、细节描写等手法③意境营造:常用景物烘托、虚实结合等手法
标志①标题常含“塞”“征”“军”“戍”等与军旅有关的字词②常见意象:自然景物类(黄沙、秋月、大漠、孤城、边关、雨雪、风沙等),地理区域类(塞外、雁门关、玉门关、黄河、阴山、楼兰、蓟北等),战事器具类(金鼓、旌旗、烽火、羌笛、琵琶、战马等),乐曲类(《梅花落》《折杨柳》《关山月》《阳关三叠》《渭城曲》等),人物类(戍卒、将帅、胡人、单于等)①保家卫国、建立功名的壮志豪情②奋勇杀敌、英勇无畏的英雄气概③雄奇瑰丽、奇异独特的边塞风光④征人思乡、闺妇盼归的两地情愁⑤凄苦哀怨的怨战情绪,凄厉沉痛的反战思考⑥对和平安宁的边疆生活、和睦友好的民族往来的喜爱①修辞手法:主要有夸张、互文、对比、用典等②人物塑造手法:常用侧面烘托、动作描写、肖像描写、细节描写等手法③意境营造:常用景物烘托、虚实结合等手法

经典例题

(2025·湖南大联考二模)阅读下面的两首唐诗,完成1—2题。

出塞二首(其二)
[盛唐]王昌龄
骝马[注]新跨白玉鞍,战罢沙场月色寒。
城头铁鼓声犹震,匣里金刀血未干。
出　塞
[晚唐]马戴
金带连环束战袍,马头冲雪过临洮。
卷旗夜劫单于帐,乱斫胡兵缺宝刀。

[注]骝马:黑鬣黑尾巴的红马,骏马的一种。

1.下列对这两首诗的理解和赏析,不正确的一项是(　　)(3分)

  • A王诗通过骝马、寒月、铁鼓、金刀等意象,描写了一场战鼓刚刚敲响的惊心动魄的战斗。
  • B王诗第三句和高适《燕歌行》中的“寒声一夜传刁斗”一句都是通过描写听觉表现战事的激烈。
  • C马诗第一句中的“金带连环”看似写战袍,目的却在表现将士们那种风神俊逸、英武逼人的丰姿。
  • D马诗第三句中的“卷旗”与李贺《雁门太守行》中的“半卷红旗”有异曲同工之妙,都是写偷袭战。
查看答案

A

查看解析

“战鼓刚刚敲响”错误。“声犹震”的“犹”表示仍然,可知战鼓不是刚刚敲响,联系前文“战罢沙场”可知,本诗描写的是战斗刚刚结束。故选A。

2.两首诗都有对“刀”的细节描写,侧面烘托了戍边将士英勇无畏的形象,请结合诗句简要分析。(6分)

查看答案

①王诗以“金刀血未干”这样一幅看似血腥的场景,表明热血并未因为战斗的结束而冷却,与前文“骝马新跨白玉鞍”等句一起塑造出英姿飒爽、威风凛凛的英雄形象。②马诗通过“宝刀”的“缺”这一细节,侧面表现出战士肉搏拼杀之烈、战斗时间之长,体现了将士忘我杀敌时的英勇无畏,与前文“马头冲雪”“夜劫单于”等细节共同塑造出视死如归的英雄形象。(每点3分)

查看解析

①“金刀血未干”描绘战斗刚结束、刀上血迹未干的场景,视觉冲击强烈,结合“骝马新跨白玉鞍”,衬托战士英姿飒爽,进一步突出其刚经历残酷战斗的英勇形象,侧面展现戍边将士的无畏精神。②“缺宝刀”暗示战士在战斗中激烈拼杀,刀砍出缺口,体现战斗的激烈与持久。与“马头冲雪”“夜劫单于”呼应,塑造战士视死如归、忘我杀敌的英勇形象。

题材四　离别怀人诗

查看答案

“表现了词人自由惬意的心境”错误。结合词中大雁“怨归迟”及词人的奔波情景可知,体现的应是思乡的愁绪,并非自由惬意。

2.这首词的上片和下片分别从离人和思妇的角度来写思念之情,请分别简要分析上片和下片是如何抒发思念之情的。(6分)

查看答案

①上片从离人角度,以大雁南飞“怨归迟”起兴,借瘦马奔波、西风扑鬓的形象,直接抒发旅途的艰辛和对家乡的思念;②下片从思妇角度,通过“人杳杳,思依依”等描写,写思妇对离人的牵挂,以窗前月寄托思念,借景抒情,表达深切的离别之苦。(每点3分)

查看解析

①上片,“雁帖寒云次第飞,向南犹自怨归迟”,大雁向南飞行本是自然规律,然而词人却说大雁“怨归迟”,以此起兴,引发后面离人对自身归期的感慨。“谁能瘦马关山道,又到西风扑鬓时”中,“瘦马”暗示了离人旅途的疲惫与艰辛,“关山道”点明了旅途的遥远和艰难,“西风扑鬓”描绘出西风猛烈地吹打着离人的鬓发,直接抒发旅途的艰辛和对家乡的思念。②下片,“人杳杳,思依依”中,“人杳杳”点明离人已经远去,“思依依”则直接点明了思妇的思念之情绵绵不绝。“凭将扫黛窗前月,持向今宵照别离”中,思妇请明月将自己的一片思念之情带给远方的离人;“今宵照别离”则进一步强调了这种离别的痛苦,在这月圆之夜,本是家人团聚的时刻,然而思妇却与离人天各一方,只能借助明月之景来寄托自己的思念。

经典例题

(2025·山东潍坊三模)阅读下面这首宋诗,完成1—2 题。

次韵和吴仲庶舍人送德化郭尉①
梅尧臣
蒲叶高帆十二幅,秋风逆水满樯开。
是时不畏浪头起,到日定将船尾堆。
用舍东方言虎鼠②,贱疏梅福比蒿莱③。
少年才辨无如美,庐岳峰前莫滞回。

[注] ①郭尉:郭祥正,在任职星子县主簿期间,与上司不合,弃官。后其重归仕途,任德化县尉。②东方言虎鼠:出自《汉书·东方朔传》“用之则为虎,不用则为鼠”。③梅福比蒿莱:典出《汉书》,梅福因王莽专权而弃官归隐。

1.下列对这首诗的理解和赏析,不正确的一项是(　　)(3分)

  • A首联极具画面感,描绘了帆船启航的场景,给人以视觉上的冲击。
  • B颔联虚实结合,既实写送别所见,又想象了到达目的地后的场景。
  • C颈联连用了东方朔和梅福的典故,表现了人才境遇的变化无常。
  • D本诗描写和议论结合,既抒发离别的愁绪,又寄寓对人生的思考。
查看答案

D

查看解析

“离别的愁绪”错误。全诗前两联以行船场景暗喻仕途挑战,后两联以典故和议论表达对友人的劝勉,通篇未直接抒发“离别的愁绪”,而是充满对友人重归仕途的期许与鼓励。

2.诗歌的尾句,有人认为传递出对友人迎难而上的勉励,也有人认为是对友人勿沉溺美景的劝诫。你同意哪种观点?请结合全诗说明理由。(6分)

查看答案

(示例一)同意前者。①诗歌前两联已借行船鼓励友人要迎难而进,必将达到目的。②作者认为友人才华出众,理应干出一番事业。③尾句以面对山峰不要停留后退为喻,鼓励友人不畏艰险,积极进取。(每点2分)

(示例二)同意后者。①郭尉曾有弃官而去的经历,作者担心友人会再次因仕途不顺而弃官。②作者认为友人才华出众,如不施展,十分可惜。③尾句劝友人面对庐岳峰之美,不要贪恋美景,应记住此行的目的。(每点2分)

查看解析

同意前者。①首联“逆水满樯开”、颔联“不畏浪头起”以行船破浪喻指仕途挑战,暗示友人需直面困难;“到日定将船尾堆”则以抵达后的收获,暗喻坚持必有所成,已奠定“迎难而进”的基调。②颈联“用舍东方”强调友人当前“被用”的机遇,“才辨无如美”直接盛赞其才华,隐含“应趁势作为”的期待。③尾句“莫滞回”以“山峰”喻阻碍,劝其勿退缩,紧扣“积极进取”的核心。

同意后者。①郭尉曾因仕途不顺弃官,作者担忧其故态复萌;“庐岳峰”既指自然美景,亦象征可能引发归隐的闲适诱惑(如官场挫折后的退避心态)。②颈联以梅福归隐为戒(“比蒿莱”),强调才华不应荒废。③尾句“莫滞回”劝其勿贪恋“峰前”之景(隐喻避世念头),应专注仕途,呼应“惜才劝进”的初衷。

(2025·江苏高品质科研卷)阅读下面这首唐诗,完成1—2题。

戏题阶前芍药①
柳宗元
凡卉与时谢,妍华丽兹晨。
欹红醉浓露,窈窕留馀春。
孤赏白日暮,暄风动摇频。
夜窗蔼芳气,幽卧知相亲。
愿致溱洧②赠,悠悠南国人。

[注] ①这首诗作于诗人被贬永州年间。②溱洧:出自《诗经·郑风·溱洧》,溱洧,郑国的两条水名,在今河南境内。古之芍药为香草名,青年男女以芍药相赠表示愿结情好。

1.下列对这首诗的理解和赏析,不正确的一项是(　　)(3分)

  • A开篇诗人写凡花随春凋谢,唯有芍药今晨开放,通过对比突出芍药花的与众不同。
  • B“欹”,倾斜,诗人写芍药花斜着身子,就像醉酒微醺的窈窕佳人,描写惟妙惟肖。
  • C第五、第六句写诗人日暮独自欣赏芍药,芍药亦在春风中频频向诗人摇手,富有情趣。
  • D诗人用戏谑的语气和轻松的笔调刻画了芍药的美好形象,寄寓了自身高洁的品性。
查看答案

C

查看解析

“芍药亦在春风中频频向诗人摇手”错误。“暄风动摇频”是说温暖的春风频繁吹拂,致使芍药花枝摇曳,这里只是描绘芍药在风中自然摆动的状态,并未赋予其向诗人“摇手”这一拟人化动作。将“动摇”曲解为“摇手”,属于过度解读,与诗句原意不符。

2.有人认为这是一首干谒诗,表达柳宗元希望得到重新起用的愿望。请结合最后两句分析其理由。(6分)

查看答案

①最后两句写希望像《溱洧》诗中的少男少女一样,摘一朵芍药赠给悠悠的江南美人;②流贬永州的诗人,就像阶前的芍药,有才德却只能孤赏;③使用典故,委婉地表达了希望有德高望重的人能从中斡旋,从而使朝廷能赏识、重用自己的愿望。(每点2分)

查看解析

①最后两句“愿致溱洧赠,悠悠南国人”,化用《诗经·郑风·溱洧》的典故,想象自己像诗中的少男少女一样,采摘芍药赠给远方的“南国人”。②诗歌前几句对阶前芍药进行了细致描写,“凡卉与时谢,妍华丽兹晨。欹红醉浓露,窈窕留馀春”,展现出芍药在众花凋零时独自绽放的美丽与优雅,它“孤赏白日暮”,无人欣赏,只能独自度过时光。诗人被贬永州,远离朝廷,有才德却无人赏识,如同这阶前独自绽放的芍药,诗人委婉地表达了自己的孤独与怀才不遇。③诗人借“溱洧赠”的典故,希望能有像《溱洧》中那样的机缘,将自己这朵“芍药”推荐给“悠悠南国人”。这里的“南国人”可象征朝廷中有权势或德高望重的人,诗人希望通过他们的斡旋,让朝廷能够看到自己的才华和品德,从而重新起用自己,实现自己的政治抱负。

题材十　题画抒怀诗

知识梳理

题材特征思想情感常用技法
内涵据绘画的内容所作之诗,即赏画者对绘画题材、内容、思想的评定,是对作品格调的艺术总结①抒发作者对画作的赞美、感叹之情②表达作者对艺术的见解③咏叹画面的意境④表达作者的心志①化静为动,动静相生。运用联想将画面上静止不动的景物、人物写活写动,画中景物、人物如在读者眼前②化实为虚,虚实相映。观察画面需要展开想象,想象出画面应有而没有画出来的景物。题画诗亦是如此,不仅写画面上有的景物,而且写画面上没有的景物③借景抒情,托物言志。大部分题画诗的作者往往借题画来表达自己的思想情感,表达自己的心志,寄托深沉的感慨,或是宣泄内心的不满

(2025·广东广州天河区二模)阅读下面两首诗歌,完成1—2题。

题春江渔父图
[元]杨维桢
一片青天白鹭前,桃花水泛住家船。
呼儿去换城中酒,新得槎头缩项鳊。
渔父词二首(其一)
[元]赵孟

渺渺烟波一叶舟,西风落木五湖秋。盟鸥鹭,傲王侯,管甚鲈鱼不上钩。

1.下列对这两首诗歌的理解和赏析,不正确的一项是(　　)(3分)

  • A杨诗前两句再现画中青天白鹭、桃花流水的春景,为下文换酒庆收获的情景作铺垫。
  • B赵词中数词的使用凸显了渔父的遗世独立与秋江的辽阔深邃,丰富了诗歌的意境。
  • C这两首诗歌意象丰富、画面感强,注重通过多个意象的叠加来表现渔父的生活情趣。
  • D杨诗语言流畅自然,以白描手法为主;赵词注重炼字炼句,平实之中尽显典雅明丽。
查看答案

D

查看解析

“尽显典雅明丽”错误。赵词语言风格并非“典雅明丽”,从“渺渺烟波”“西风落木”等词句可看出其意境较为清冷、旷远,语言风格是质朴、自然且带有一种超脱的韵味,并非典雅明丽。

2.这两首诗歌的最后一句都写到了“鱼”这一意象,其作用有何不同?(6分)

查看答案

①杨诗中的鱼是渔人的劳动成果,表现了渔父丰收的喜悦及诗人对渔家生活的向往之情。②赵词借鱼来象征身外之物,凸显了渔父超然物外、闲淡自适、不为外物所累的精神境界。(每点3分)

查看解析

①杨诗“新得槎头缩项鳊”中鱼的意象代表着渔父的劳动成果。渔父捕到鱼后“呼儿去换城中酒”,体现出收获的喜悦,突出了渔父生活的惬意和满足,展现了一种平凡而美好的生活场景,同时表现了诗人对渔家安宁惬意生活的向往之情。②赵词“管甚鲈鱼不上钩”中鱼的意象是一种象征。“鲈鱼”常被视为名利的象征,渔父“管甚鲈鱼不上钩”,表明他不在乎是否能钓到象征名利的“鱼”,突出了渔父淡泊名利、傲世独立的精神品质,表达了他对世俗名利的不屑和超然物外、闲淡自适、不为外物所累的精神境界。
