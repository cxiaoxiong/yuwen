二项式定理的应用：指定项系数的求解 学历案

——高三 · 高三一轮复习·二项式定理（第1课时）｜复习课｜1课时，40分钟

【学习主题】

二项式定理的应用——求展开式中指定项的系数：回顾二项式定理及其推导中蕴含的组合原理；用通项公式解决二项式和两因式乘积型的指定项系数问题；把三项展开式“转化”为二项式，或直接用组合计数求解，并推广到一般公式。（1课时，40分钟）

【课标与学业质量要求】

1. 能用多项式运算法则和计数原理证明二项式定理，会用二项式定理解决与二项展开式有关的简单问题（数学运算、逻辑推理）。

2. 在把三项式问题转化为二项式问题的过程中，体会化归与转化的思想（逻辑推理、数学抽象）。

学业质量：对应水平二，能在熟悉和关联的情境中，选择恰当的方法求展开式中指定项的系数，并说明方法的依据。

【学习目标】

G1 能写出二项式定理与通项公式，并用“每个括号取一项”的组合观点说明第 r+1 项系数为 Cnr 的原因。（L1—L2）

G2 能用通项公式求二项展开式和形如 (a+b)(c+d)n 的展开式中指定项的系数，限时8分钟完成练习1、练习2共4题，至少对3题。（L2—L3）

G3 能用“转化为二项式”和“组合计数”两种方法求三项展开式中指定项的系数，并说出各自适合的情形。（L3—L4）

G4 能把组合计数推广为 (a+b+c)n 中 apbqcr 项系数的一般公式，并在3分钟内用它解一道新题；能对自己的错题写出“错因三问”。（L4—L5）

【评价任务】

编码评价任务对应目标完成标准
T1课前准备的展示：写出定理与通项，口述系数的组合来历G1定理、通项书写无误；能用“从 n 个括号中选 r 个取 b”说清 Cnr
T2练习1、练习2限时完成，同桌互批G24题至少对3题；每题写出所用的通项
T3探究1：同一道题用两种方法各做一遍G3两种方法都得到正确结果；能说出何时用哪种
T4探究2推广公式；练习3；当堂检测与错因三问G4公式正确；练习3至少对3题；错题都有错因诊断

【学法建议】

① 抓“组合观点”：(a+b)n 是 n 个括号相乘，展开式的每一项都是“每个括号各取一项”乘出来的，系数就是取法的种数。

② 先写通项，再定 r：求指定项，先写出 Tr+1，整理 x 的指数，令它等于目标指数，解出 r。

③ 遇到三项，先想转化：能分组就把两项看成一个整体；不好分组时，直接数“每个括号取哪一项”。

④ 错因三问：错在哪一步？依据的是什么规则？正确做法是什么？

【参考答案】教师用

课前准备　(a+b)n=Cn0an+Cn1an−1b+⋯+Cnran−rbr+⋯+Cnnbn (n∈𝐍∗)；Tr+1=Cnran−rbr。(a+b)n 是 n 个 (a+b) 相乘，含 an−rbr 的项，是从 n 个括号中选出 r 个取 b、其余取 a 得到的，取法有 Cnr 种。

活动一　2；C52=10

练习1　（1）Tr+1=C7rxr，r=2，系数为 C72=21。（2）Tr+1=C5r(x2)5−r(ax)r=C5rarx10−3r，令 10−3r=7，得 r=1，5a=−10，a=−2。

练习2　（1）x2 项来自 1⋅C62x2 与 1x2⋅C64x4，系数为 15+15=30。（2）(2x−1)5 中 x2 项系数为 C52⋅22⋅(−1)3=−40，x3 项系数为 C53⋅23⋅(−1)2=80，所求为 1×(−40)+1×80=40。小结：分别找出两个因式中“配对”能凑成目标次数的项，系数相乘再相加。

探究1　方法一：把 1+x 看成整体，Tk+1=C10k(1+x)10−kx−2015k，只有 k=0 时才可能出现 x2，所以系数为 C102=45。方法二：10个括号中选2个取 x，其余8个取1，取法有 C102=45 种。比较：能把两项合成整体、且另一项很快被排除时，转化简便；三项都可能参与时，直接组合计数更清楚。

探究2　先从 n 个括号中选 p 个取 a，再从剩下的 n−p 个中选 q 个取 b，其余取 c，系数为 CnpCn−pq=n!p!q!r!。

练习3　（1）6!1!2!3!=60　（2）选3个括号取 c：C63=20；剩下3个括号取 a2、a 凑成 a5，需两个 a2、一个 a：C32=3；系数为 60。　（3）选2个括号取 y：C52=10；剩下3个括号凑 x5，需两个 x2、一个 x：C32=3；系数为 30。　（4）把 2x−x2 看成整体：C42(2x−x2)2 中 x3 项系数为 6×(−4)=−24，C43(2x−x2)3 中 x3 项系数为 4×8=32，合计 8。

当堂检测　1. Tr+1=C6r(−2)rx6−2r，r=3，常数项为 20×(−8)=−160。　2. 1×C52+(−2)×C51=10−10=0。　3. 5!2!1!2!=30。

A组　1. Tr+1=C7rarx7−r，r=3，35a3=−280，a=−2。　2. Tr+1=C6r(−1)rx12−3r，r=4，常数项为 15。　3. 2Cn2=Cn1+Cn3，化简得 n2−9n+14=0，n=7（n=2 不合题意，舍去）；Tr+1=C7rx7−2r，令 7−2r=5，r=1，系数为 7。

B组　4. (x2+3x+2)5=(x+1)5(x+2)5，x 项系数为 5×25+1×C51×24=160+80=240。　5. 方法一：(1+x+x2)4=[(1+x)+x2]4，x3 项来自 C40(1+x)4 中的 x3（系数4）和 C41(1+x)3x2 中的 x3（系数 4×3=12），合计 16。方法二：取三个 x、一个1：C43=4；取一个 x2、一个 x、两个1：4×3=12；合计 16。

C组　1+x+x2+x3=(1+x)(1+x2)，原式 =(1+x)4(1+x2)4，x3 项系数为 C43×1+C41×C41=4+16=20。四项式可尝试因式分解或分组，转化为两个二项式的乘积。

【教学设计】教师用

一、教学内容与学情分析

本课是二项式定理复习的第一课时，要解决两个问题：会求展开式中指定项的系数（高考常见题型）；理解二项式定理推导中的组合原理（它为三项式甚至多项式的系数问题指明了方向）。

学情：高三学生会套通项公式解二项式问题，但对“系数从哪里来”只记结论；遇到三项式时不知道怎样转化，或者转化后计算混乱。原课例的检测目标一栏是空的，目标“提高能力”“提升素养”无法检验，全部公式又是图片，无法编辑；本版重写了目标与评价任务，公式全部改为可编辑的形式，并补上了全部答案。

二、教学重难点

重点：用通项公式求指定项的系数。

难点：三项展开式指定项系数的两种求法及其选择。

四、板书设计

左栏：二项式定理与通项 Tr+1=Cnran−rbr；求指定项：写通项 → 整理指数 → 解 r → 算系数。

中栏：乘积型 (a+b)(c+d)n：分别配对，相乘再相加。

右栏：三项式：转化（两项看作整体）／组合计数 n!p!q!r!。
