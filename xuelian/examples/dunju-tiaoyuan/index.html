初中体育学练单：把蹲踞式跳远拆成助跑、起跳、腾空、落地四个环节，分解练习、逐级连接，起跳脚、落地缓冲都有可数可看的标准，小组轮换当观察员与测量员，配跳跃体能和安全提示。

田径：蹲踞式跳远 学历案

——八年级 · 体育与健康·田径（跳跃）单元（第1课时）｜新授课｜1课时，45分钟

【学习主题】

蹲踞式跳远：认识助跑、起跳、腾空、落地四个技术环节，通过分解练习和逐级连接，初步掌握短程助跑起跳与“蹲踞”姿势落地的完整动作；发展下肢力量、速度和协调性；在小组学练中如实测量、互相帮助，学会预防跳跃中的运动损伤。（第1课时，45分钟）

【课标与学业质量要求】

1. 初步掌握蹲踞式跳远的技术动作，并能在练习和测试中运用（运动能力）。

2. 知道跳跃练习中预防踝、膝损伤的方法，主动做好热身与放松（健康行为）。

3. 在小组学练中遵守规则、如实测量、互相鼓励（体育品德）。

学业质量：课标中学业要求的具体表述请以学校所用的《义务教育体育与健康课程标准》为准；本课着重落实“能完成基本技术动作并说出要领”“在练习中表现出安全意识和合作行为”。

【学习目标】

G1 能按顺序说出蹲踞式跳远的四个技术环节，并做出起跳与落地两个分解动作。（L1—L2）

G2 能在6—8步短程助跑后完成单脚有力起跳、越过起跳区前方的标志线，10次中至少7次用同一只脚踏跳。（L2—L3）

G3 能完成助跑、起跳、腾空、落地的完整动作，落地时两腿前伸、屈膝缓冲，同伴按量规评价达到“合格”以上。（L3—L4）

G4 能完成跳跃体能组合练习，达到计分表“合格”以上；担任测量员时如实测量和记录。（L2）

【评价任务】

编码评价任务对应目标完成标准
T1口述四个环节；原地做起跳摆臂、落地缓冲分解动作G1顺序正确；分解动作要点做到
T2短程助跑起跳10次，同伴记录踏跳脚G2至少7次同一只脚起跳；起跳后身体向前上方腾起
T3完整动作3次，观察员按量规评价G3量规达到“合格”以上
T4跳跃体能组合计数；测量员记录表G4达到“合格”以上；记录如实、完整

【学法建议】

① 先找起跳脚：原地单脚跳几次，用得最顺、最有力的那只脚就是你的起跳脚。

② 起跳要“踏”不要“踩”：起跳脚快速有力地踏板，摆动腿屈膝向前上方摆，两臂配合上摆。

③ 落地要“伸”和“屈”：两腿尽量前伸，脚跟着地后马上屈膝，身体前倾，不要向后坐。

④ 当观察员时只看一个点：这一轮看起跳脚，下一轮看落地，不要什么都看。

一、课前准备（约5分钟）

1. 观看一段蹲踞式跳远的慢动作视频（教师提供），说出你看到的四个环节：

2. 想一想：跳远时，怎样落地才不容易受伤？

二、课中学习（45分钟）

活动一　准备部分：热身与专项准备〔8分钟〕

1. 慢跑400米；徒手操；重点活动踝关节、膝关节（踝关节绕环、弓步压腿各8拍×2）。

2. 专项准备：原地单脚连续跳（左右各10次），找出自己的起跳脚。

安全提示：检查沙坑已翻松、耙平，无石块和杂物；穿运动鞋，系好鞋带。

活动二　认识四个环节与分解动作〔T1｜6分钟〕

1. 看教师示范完整动作和分解动作，说出四个环节： → → →

2. 原地练习：

（1）起跳摆臂：起跳脚在前，摆动腿屈膝向前上方摆起，两臂同时上摆，做10次。

（2）落地缓冲：从台阶（约30厘米）上跳下，两脚并拢、屈膝缓冲、身体前倾，做5次。

活动三　短程助跑起跳〔T2｜10分钟〕

1. 6—8步助跑，单脚踏跳，越过起跳区前方约1米处的标志线，落入沙坑（先不要求落地姿势）。

2. 同伴记录：

3. 想一想：每次起跳的脚不一样，可能是什么原因？怎样调整助跑步数？

活动四　完整动作与互评〔T3｜11分钟〕

1. 完整练习：短程助跑 → 起跳 → 腾空步后两腿屈膝靠拢成“蹲踞” → 两腿前伸落地、屈膝缓冲。每人至少3次。

2. 观察员按下表评价（每轮只看一个要点，三轮看完三个要点）：

等级起跳腾空落地
优秀踏跳有力，摆动腿积极上摆两腿屈膝靠拢成明显的蹲踞姿势两腿前伸，脚跟先着地，屈膝缓冲，身体前倾
合格能单脚起跳，摆腿不够积极有收腿动作，但姿势不明显两脚落地，有屈膝缓冲
待提高双脚起跳或踏跳无力腾空后两腿分开，没有收腿落地后身体后坐或直腿落地

3. 测量员在沙坑边用皮尺测量每人最好一次的成绩，如实记录：米

三项循环，每项30秒、间歇15秒；同伴计数。

活动六　放松与小结〔4分钟〕

拉伸大腿前后侧和小腿；用一句话说出今天自己最需要改进的一个环节；填写学后反思。

【作业与检测】

当堂检测

活动二的口述与分解动作（T1）、活动三的起跳记录（T2）、活动四的完整动作量规（T3）、活动五的体能计分与测量员记录（T4）均在课上完成，即本课的当堂检测。

课后分层作业

A 基础巩固（全体完成）

1.（G1）对着镜子练习起跳摆臂动作30次，说出动作要领。

B 能力提升（中等及以上完成）

2.（G4）每天完成立定跳远10次、蛙跳2组，记录一周的立定跳远最好成绩。

C 拔尖挑战（选做）

3.（G3）请家人用手机拍下你的一次完整跳远（在安全场地），对照量规找出一个问题，写出改进办法。

【参考答案】教师用

活动二　助跑 → 起跳 → 腾空 → 落地。

活动三　起跳脚不固定的原因：助跑步数不固定、步幅忽大忽小、不熟悉自己的起跳脚。调整办法：固定助跑步数和起点，在起跳点做标记，反复练习。

课前准备　落地时两腿前伸，脚跟着地后立即屈膝缓冲，身体前倾，避免直腿落地或向后坐倒。

【教学设计】教师用

一、教学内容与学情分析

本课是田径跳跃单元的第1课时。八年级学生有一定的跑跳基础，但多数人起跳脚不固定、起跳无力，落地时直腿或向后坐，容易受伤。本课把完整技术拆成四个环节，先分解、后连接，用可以数的标准（同一只脚起跳的次数）和可以看的量规（三个要点）让学生知道自己做到了哪一步。

本课改写自本地课例：原课例的目标包含“理解”“增强情绪调控能力”等难以在课上检验的表述，评价任务没有完成标准，学后反思为空白。本版保留了“分解练习—完整练习—比赛与体能”的结构，把目标写成可以观察和计数的动作表现。

二、教学重难点

重点：单脚有力起跳与屈膝缓冲落地。

难点：助跑与起跳的衔接（起跳脚固定、踏跳准确）。

三、45分钟时间预算与运动负荷

环节内容时长累计组织与负荷
活动一热身与专项准备8′8′集体；中等强度
活动二四个环节与分解动作6′14′集体示范，原地练习
活动三短程助跑起跳10′24′分4组在两个沙坑轮换，减少等待
活动四完整动作与互评11′35′每组设观察员、测量员，轮换
活动五跳跃体能组合6′41′30秒练、15秒歇；强度较高
活动六放松与小结4′45′集体拉伸

四、场地与安全

沙坑课前翻松耙平，检查无石块、玻璃等杂物；起跳区地面平整防滑；学生按顺序依次起跳，前一人离开沙坑后后一人才能起跳。出现踝、膝疼痛立即停止练习并报告。

五、课后反思提纲

1. 起跳脚固定（10次中7次以上）的学生比例是多少？

2. 落地量规达到“合格”以上的有多少？直腿落地的学生如何个别指导？

3. 分组轮换是否减少了等待？每名学生实际起跳了多少次？
