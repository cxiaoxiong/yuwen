离子反应 学历案

——高一 · 人教版必修第一册第一章第二节（第2课时）｜新授课｜1课时，40分钟

【学习主题】

离子反应：从“溶液混合后离子发生了什么变化”出发，借助实验现象和电导率数据认识离子反应的实质与复分解型离子反应发生的条件；建立“写、拆、删、查”四步书写模型，突破“哪些物质能拆”的难点；用离子方程式解释导电能力曲线和泡腾片产生气泡的现象。（1课时，40分钟）

【课标与学业质量要求】

1. 认识酸、碱、盐在水溶液中能发生电离；了解离子反应及其发生的条件，能用离子方程式表示水溶液中的离子反应（宏观辨识与微观探析）。

2. 能基于实验现象和数据进行推理，建立书写离子方程式的思维模型（证据推理与模型认知）。

3. 能设计并完成简单的验证实验，如实记录现象和数据（科学探究与创新意识）。

学业质量：对应水平二—三，能从微观离子的角度分析水溶液中的反应，正确书写简单的离子方程式，并结合实验证据进行推理。

【学习目标】

G1 能通过三组溶液混合实验与电导率变化，用“反应前离子—反应后离子”对比表归纳离子反应的实质，并说出复分解型离子反应发生的三个条件。（L2）

G2 能用“写、拆、删、查”四步模型判断9种物质能否拆写（至少对8种），并独立写对两类典型反应的离子方程式，说出每一步的依据。（L3）

G3 能依据“导电能力取决于自由移动离子的浓度”，解释氢氧化钡溶液中滴加稀硫酸时导电能力曲线各段的变化。（L3—L4）

G4 能写出醋酸与碳酸氢钠反应的离子方程式，揭开泡腾片的“气泡之谜”，并用“错因三问”整理出自己的2条易错点。（L4—L5）

【评价任务】

编码评价任务对应目标完成标准
T1小组完成“实验统整表”，归纳实质与条件，回答“氯化钠与硝酸钾”反例G1统整表离子对比全部正确；三个条件说全；反例能用“离子没有减少”作答
T29种物质快辨；两道离子方程式独立书写、同桌互查、板演G2快辨对8种以上；两道方程式全对且电荷守恒；板演能说出“拆”的依据
T3解读导电能力曲线，选出正确说法并说明理由G3选对，并能说出B点和BC段离子浓度的变化
T4写出泡腾片反应的离子方程式；完成易错清单与错因三问G4方程式正确（醋酸、碳酸氢根不拆）；2条易错点具体到“哪一步、哪条规则”

【学法建议】

① 三重表征：宏观现象 → 微观离子 → 化学符号，每看到一个现象都追问“溶液里的离子发生了什么变化”。

② “拆”看两条：是否易溶、是否易电离。难溶物、弱酸弱碱、水、气体、氧化物、单质都写化学式。

③ “查”看两样：原子守恒＋电荷守恒，缺一不可。

④ 错因三问：错在哪一步？这一步的规则是什么？下次先查什么？

课前准备　1. 导电；NaHCO3=Na++HCO3−；Ba(OH)2=Ba2++2OH−；CH3COOH⇌CH3COO−+H+　2. 离子；离子；离子；离子

活动二　①无明显现象（溶液温度略升）；H+、OH−；电导率下降。②产生白色沉淀；反应前 Na+、SO42−、Ba2+、Cl−，减少 Ba2+、SO42−；电导率下降。③产生气泡；反应前 H+、SO42−、Na+、CO32−，减少 H+、CO32−；电导率下降。归纳：1. 浓度　2. 沉淀、气体、水（难电离的物质）　3. 没有发生离子反应，混合后没有生成沉淀、气体或水，溶液中各离子浓度没有减少。

活动三　1. 能拆：NaHCO3（拆成 Na+ 和 HCO3−）、KOH、HCl、NaHSO4、KNO3；不能拆：CaCO3、Zn、H2O、SO2。　3.（1）H++OH−=H2O（2）CaCO3+2H+=Ca2++H2O+CO2↑　4. 同一类型的离子反应（如强酸与强碱生成可溶性盐和水的反应）。

活动四　1.（1）Ba2++2OH−+2H++SO42−=BaSO4↓+2H2O（2）B。A错：BaSO4 是电解质，导电能力减弱是因为离子生成了沉淀和水；C错：BC段导电能力增大是因为加入的稀硫酸过量。　2. CH3COOH+HCO3−=CH3COO−+H2O+CO2↑；泡腾片溶于水后，酸电离出的 H+ 与 HCO3− 结合生成二氧化碳和水，固体时离子不能自由移动，所以干燥时不反应。

A组　1. B　2. B（A中碳酸钙不拆；C中醋酸不拆；D中 HCO3− 不拆，应为 HCO3−+H+=H2O+CO2↑）　3. H++OH−=H2O；Zn+2H+=Zn2++H2↑

B组　4. A（B中碱性溶液里 Cu2+ 生成沉淀；C中 H+ 与 CO32− 反应；D中溶液呈酸性，CO32− 不能大量存在，且 Ca2+ 与 CO32− 生成沉淀）　5. ① HCO3− 是弱酸的酸式酸根，书写时保留原样；②醋酸是弱酸，难电离，写化学式；③电荷不守恒（左边3个正电荷，右边4个），正确为 Fe+2Fe3+=3Fe2+。

C组　硫酸是强酸，HSO4− 在水中完全电离出 H+ 和 SO42−；碳酸是弱酸，HCO3− 是其第二步电离的产物，电离程度很小，在水中主要以 HCO3− 形式存在，所以不拆。

【教学设计】教师用

一、教学内容与学情分析

本课承接“电解质的电离”，是学生第一次从离子的视角重新审视复分解反应，“宏观—微观—符号”的思维方式会贯穿此后的整个水溶液内容。

学情：学生会写简单的电离方程式，但“看不见”溶液中的离子；拆写边界混乱（碳酸氢根、弱酸、难溶物）；书写时只查原子守恒、忽视电荷守恒。对策：电导率曲线把离子浓度变化可视化；快辨暴露拆写错误、只讲错误率高的项；“查”一步单列电荷守恒。

二、教学重难点

重点：离子反应的实质与复分解型离子反应发生的条件；“写拆删查”四步模型。

难点：拆写边界的判断（弱酸、酸式酸根、难溶物）。

三、40分钟时间预算与“红灯线”

环节内容时长累计红灯线（超时怎么办）
活动一泡腾片演示、设悬念3′3′超过4分钟即收，猜想留到课尾
活动二三组实验、统整表、归纳15′18′实验③只记现象，离子对比课后补全
活动三快辨、精写两道、互查板演13′31′板演只留一组；只讲错误率最高的两种物质
活动四曲线解读、揭开悬念6′37′曲线题只讲选项C；悬念方程式必须保留
活动五易错清单3′40′写不完的带回家完成

原课例的教训：最初的设计含三张六行实验表、9种物质书面分类、4道方程式、两个迁移情境和3例改错，实际需要55分钟以上。本版把三张表合成一张、快辨改为手势、课中只精写两道，其余移入课后作业。

四、板书设计

左栏（知识主线）：泡腾片之谜 → 三组实验＋电导率 → 实质：离子浓度减小 → 条件：沉淀、气体、水 → 离子方程式（一式表一类）。

右栏（模型与密码）：写 → 拆（易溶易电离才拆）→ 删 → 查（原子守恒＋电荷守恒）；气泡密码：CH3COOH+HCO3−→CH3COO−+H2O+CO2。

五、课后反思提纲

1. 快辨中哪几种物质错误率最高？下节课如何补偿？

2. 两道精写的全对率是多少？电荷守恒的错误有多少？

3. 分组实验中负责读曲线的学生，是否真正参与了离子分析？

4. 时间预算是否兑现？哪个环节触发了红灯线？

G1、G2……Goal（目标）学习目标的编号每条学习目标前面的编号，按从低到高排列。评价任务、作业题、反思问题都用它标出「对应哪条目标」。G2 能判断一条目标是否可观测，指出其中“看不见、测不了”的动词。（L2）
T1、T2……Task（任务）评价任务的编号每项评价任务的编号。评价任务表里写明它「对应目标」；学习活动的标题里写「〔T2｜12 分钟〕」，表示这个活动落实哪项评价任务。T2（对应 G2）理解性默写自测，限时 8 分钟，7 题中至少 6 题全对。
L1—L5Level（层级）学习层级写在每条目标末尾的括号里，表示这条目标的认知要求，从 L1 识记理解到 L5 迁移创造。这是本站采用的五级划分，用来给目标排先后、搭台阶，不是官方统一标准。能写出二项展开式的通项公式。（L1）
〔T2｜12 分钟〕活动标注写在学习活动标题的末尾：这个活动落实哪项评价任务、预计用几分钟。把各活动的分钟数加起来，就能检查课时装不装得下。活动二　错题医院〔T2｜10 分钟〕
A／B／C作业分层课后作业的三层：A 基础巩固（全体做，约 L2）、B 能力提升（L3—L4）、C 拔尖挑战（选做，L5）。层与层之间是思维层级的梯度，不是题量的多少。A 订正并整理清单；B 变式辨析、说理；C 新情境任务或自己命一道题。

学习层级 L1—L5

层级名称学生的表现
L1识记理解说出概念、写出公式、找出信息。
L2初步应用套用规则或方法完成基础任务。
L3综合分析面对变式，自己选择方法、分析原因。
L4评价思辨辨析、诊断，说清为什么。
L5迁移创造在新情境中运用，或自己命题、创作。
