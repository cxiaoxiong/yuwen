喀斯特地貌 学历案

——高一 · 人教版必修第一册第四章第一节“常见地貌类型”（第1课时）｜新授课｜1课时，40分钟

【学习主题】

喀斯特地貌的分布、类型与成因：借助《徐霞客游记》的记述和景观图，认识我国喀斯特地貌的主要分布区，识别地上、地下喀斯特地貌并描述其特征；从岩石、水、气候三方面说明形成条件，理解溶蚀与沉积；分析喀斯特地貌对人类活动的影响和石漠化的治理。（第1课时，40分钟）

【课标与学业质量要求】

1. 通过野外观察或运用视频、图像，识别3—4种地貌，说明其景观的主要特点（课标必修内容要求，地理实践力、区域认知）。

2. 能运用自然地理基础知识，说明一些自然现象之间的关系和变化过程（综合思维）。

3. 能从人地关系的角度认识喀斯特地区的发展问题（人地协调观）。

学业质量：对应水平二—三，能在给定景观图和区域材料中识别地貌、说明其形成过程，并从人地协调的角度提出建议。

【学习目标】

G1 能在中国喀斯特分布图上指出主要分布省区，并结合徐霞客对粤西、滇南、黔南三地山峰的描述，从“峰体形态”“土石比例”两方面比较三地差异。（L1—L2）

G2 能将8种喀斯特地貌的景观图与名称正确配对，把地上喀斯特地貌按发育阶段排序，并用“形态＋部位＋组合”三要素描述其中一种。（L2）

G3 能从岩石、水、气候三方面说明喀斯特地貌的形成条件，写出溶蚀与沉积的化学方程式，并据此解释石钟乳、石笋的生长方向。（L3）

G4 能从地形、水文、土壤三个角度分析喀斯特山区对人类活动的利弊，判断石漠化的主要成因，提出至少两条因地制宜的建议。（L4—L5）

【评价任务】

编码评价任务对应目标完成标准
T1读分布图并完成“三地山峰对比表”G1说出广西、贵州、云南等主要省区；对比表两个维度都填对
T2地上、地下探险队：景观图配对、演化排序、一分钟描述G2配对全对；排序为溶沟石芽→洼地→峰丛→峰林→孤峰残丘；描述含三要素
T3溶蚀实验与“形成条件归纳表”G3三个条件说全；方程式正确；能用“二氧化碳逸出、碳酸钙沉淀”解释石钟乳
T4喀斯特峰丛山区利弊分析表；石漠化成因判断与建议G4利弊覆盖三个角度；指出植被破坏是主要人为原因；建议切合当地实际

【学法建议】

① 读图三步：先定“在哪里”（区域），再看“长什么样”（形态），最后问“为什么”（成因）。

② 字义记忆：“钟乳”像倒挂的乳头，自上向下；“笋”破土而出，自下向上。

③ 先猜后证：每个结论先写下自己的直觉，再找证据核对，重点记下“我原来是怎么想的”。

【参考答案】教师用

预习填空　1. 可溶性　2. 广西、贵州、云南　3. 相连；分离　4. 石钟乳；石笋；石柱

活动二　分布：集中在西南地区（广西、贵州、云南），湖南、湖北、四川、重庆、广东等地也有分布。粤西：纯石、间石，各自分行独挺——峰体分散、独立挺拔；石多土少。滇南：土峰缭绕、环洼为多——多土山，洼地环绕；土多石少（“缀石十不一二”）。黔南：界于二者之间、逼耸见奇——峰体高耸密集；土石比例介于两者之间。

活动三　演化排序：溶沟石芽→洼地→峰丛→峰林→孤峰残丘；结论：溶蚀。石钟乳长在洞顶，自上向下长；石笋长在洞底，自下向上长。

活动四　1. 清水中无明显变化；白醋中蛋壳表面产生气泡并逐渐变薄；碳酸钙能被酸性的水溶解。　2. 溶洞、洼地、溶沟等；石钟乳、石笋、石柱等。　3. 不一定。还需要可溶性岩石广布、岩石裂隙发育、水能流动；岩石不可溶的地区降水再多也难以发育喀斯特。　4. 岩石：可溶性的碳酸盐岩（石灰岩等），裂隙发育——提供被溶蚀的物质和水流通道；水：含二氧化碳、具有溶蚀力，且处于流动状态——不断溶解并带走碳酸钙；气候：高温多雨——降水多、生物活动旺盛，土壤中二氧化碳多，溶蚀力强。

活动五　1. 地形：不利——地表崎岖、平地少，耕地分散，修路难；有利——奇峰异洞，旅游资源丰富。水文：不利——地表水易渗漏，地表缺水；有利——地下河、泉水可作水源。土壤：不利——土层薄、贫瘠，易石漠化；有利——石灰岩可作建材原料，可发展耐瘠薄的特色林果、药材。　2. 主要是人为原因：喀斯特地区土层薄、易流失是先天条件，但石漠化的直接原因是陡坡开荒、过度樵采和放牧破坏了植被。沼气替代薪柴，减少砍伐，保护植被，从而保持水土。　3. 示例：发展生态旅游；种植特色经济林木与药材；继续封山育林、退耕还林；改善交通等基础设施。

活动六　悬念揭晓示例：三地差异与地势、溶蚀发育程度和土层厚薄有关。广西地势较低，溶蚀时间长、发育充分，多峰林、孤峰，石多土少；贵州地势较高，河流下切深，多峰丛，山峰高耸密集；云南高原面上土层相对较厚，多土山与洼地。（具体成因较复杂，第2课时继续探究）

当堂检测　1. A　2. C　3. C

B组　（1）人口增长，陡坡开荒、毁林种地；生活燃料依赖薪柴，过度砍伐；过度放牧。植被破坏后，土层薄的喀斯特地区水土迅速流失，岩石裸露。（2）沼气为农户提供燃料，替代薪柴，减少砍伐、保护植被；沼渣沼液可作肥料，改良土壤。（3）发展生态旅游、研学旅游；发展林下经济和农产品加工；完善交通设施；继续退耕还林、封山育林。

【教学设计】教师用

一、教学内容与学情分析

本节是“地貌”一章的开篇。喀斯特地貌是学生第一次系统接触“化学溶蚀”这种外力方式，此前学到的侵蚀多是机械冲刷，这一转变本身就是认知门槛。

学情：学生学过外力作用的基本形式，化学课学过碳酸钙与二氧化碳、水的反应。常见的错误直觉有五个：喀斯特是被水“冲”出来的；山越发育越高大；石钟乳、石笋方向混淆；降水多就一定发育；石漠化是天灾。本课用五处“先猜后证”逐一对准。

二、教学重难点

重点：地上、地下喀斯特地貌的类型与景观特征；形成条件。

难点：地上喀斯特的演化方向（地面被溶蚀降低）；溶蚀与沉积是同一反应的正逆两个方向。
